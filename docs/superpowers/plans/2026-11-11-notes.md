# Notas rápidas — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integración "Notas" en el notch: lista de notas con crear, buscar, editar, fijar, copiar y borrar con deshacer, guardadas en `userData/notes.json`.

**Architecture:** Igual que los recordatorios: esquema compartido → store JSON (fs-atomic, cuarentena) → servicio serializado con búfer de borradas recientes → integración Electron (puerta `ready`, `clipboard.writeText` por id, eventos al notch) → vista `notes` 420×320.

**Tech Stack:** Electron 45, TypeScript 6, React 19, Zustand, zod 4, Lucide, Vitest, Playwright `_electron`.

**Spec:** `docs/superpowers/specs/2026-11-11-notes-design.md`.

## Global Constraints

- Texto: 1–**2000** caracteres tras recortar, multilínea, al menos un carácter visible (misma idea que `hasVisibleText` de recordatorios). Máximo **500** notas.
- Orden: fijadas primero; dentro de cada grupo `updatedAt` descendente. Fijar no cambia `updatedAt`.
- Deshacer: barra **5 s** en la UI; main restaura solo notas borradas hace ≤ **10 s** y cuyo id no exista.
- Todos los canales `notes:*` **solo desde el notch**; el portapapeles lo escribe main por `id`.
- El log nunca contiene texto de notas (solo ids y recuentos).
- Panel `notes` **420×320**; icono `StickyNote`; ≥ 24 px; i18n ES/EN; búsqueda sin mayúsculas ni acentos (NFD sin diacríticos).
- Sin commits por tarea. No modificar `eslint.config.mjs`. Nunca manejar el escritorio del usuario.

## Review Focus

1. **Editar una nota que se borra desde otra acción** → el editor se cierra sin error ni resurrección (Task 6).
2. **Deshacer dos borrados seguidos** → cada uno restaura su nota mientras esté dentro de su ventana (Task 3, Task 6).
3. **Texto con solo espacios o saltos** → rechazado con aviso, no se crea nota vacía (Task 1, Task 6).
4. **Búsqueda con acentos en la consulta o en la nota** ("CANCIÓN" ↔ "cancion") → coincide (Task 1).
5. **Archivo corrupto** → cuarentena y lista vacía con aviso; nunca se sobrescribe un archivo más nuevo (Task 2).
