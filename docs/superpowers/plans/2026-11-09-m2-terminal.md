# M2 · Terminal PowerShell en el notch — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fila de integraciones en el panel expandido cuyo primer icono abre una terminal real de PowerShell (640×360) dentro del notch, con sesión persistente y aislada.

**Architecture:** El proceso main posee una única sesión `node-pty` (`src/main/terminal/`) y la expone por canales IPC `terminal:*` validados con zod que solo acepta el webContents del notch. El renderer del notch añade un modo `terminal` a la máquina de estados y pinta xterm.js con el tema Obsidian.

**Tech Stack:** Electron 45.2.3, TypeScript 6, React 19, Motion, zod 4, Vitest 5, Playwright `_electron`, `node-pty@1.1.0`, `@xterm/xterm@6.0.0`, `@xterm/addon-fit@0.11.0`.

**Spec:** `docs/superpowers/specs/2026-11-09-m2-terminal-design.md` (+ `docs/spikes/m2-pty-findings.md`).

## Global Constraints

- Versiones exactas fijadas en `package.json` (sin `^`), como el resto del proyecto.
- Nunca llamar a `pty.kill()` ni usar `useConptyDll`.
- Shell: `pwsh.exe` si existe; si no, `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`. Argumentos fijos `['-NoLogo']`, `name: 'xterm-256color'`, cwd = `os.homedir()`, 100×20 inicial.
- Panel de terminal: 640×360 DIP. Morph y foco siguen DESIGN.md (spring 380/32 al crecer, 180 ms al encoger).
- Escala tipográfica solo 11 / 12.5 / 13 / 15 px; Geist Mono para la terminal (13 px).
- Todo texto visible pasa por i18n ES/EN.
- Nunca registrar en logs la entrada ni la salida del shell.
- CSP de producción: único cambio `style-src 'self' 'unsafe-inline'`.
- No modificar `eslint.config.mjs` (hook de protección). No push.

## Review Focus

1. **Salida masiva** (`Get-ChildItem -Recurse C:\`): la UI no se congela; el búfer de historial no crece sin límite → test de búfer circular en Task 5.
2. **El shell muere** (`exit`, o PowerShell se cierra solo): la vista muestra «sesión terminada» y Enter crea una nueva → tests de `exit` + reapertura en Task 5 y E2E en Task 9.
3. **Entrada de otro remitente** (Control Center o URL no confiable) en `terminal:input`: `FORBIDDEN` y cero escrituras → tabla en Task 6 y E2E en Task 9.
4. **Resize con el panel encogiéndose** (cols/rows 0 o absurdos al animar): se ignora fuera de rango → test de límites en Task 6 y guard en el renderer (Task 8: no enviar resize con cols < 2).
5. **Pegar texto grande (> 64 KiB)**: el renderer trocea en bloques ≤ 64 KiB en vez de perder la entrada → test unitario de `chunkInput` en Task 8.

### Task 5: Sesión de terminal

**Files:**

**Interfaces:**
- Produces:
  ```ts
  export interface PtyLike { readonly pid: number; write(data: string): void; resize(cols: number, rows: number): void
    onData(cb: (data: string) => void): { dispose(): void }; onExit(cb: (e: { exitCode: number }) => void): { dispose(): void } }
  export type SpawnPty = (file: string, args: string[], options: { name: string; cols: number; rows: number; cwd: string; env: Record<string, string> }) => PtyLike
  export interface TerminalSnapshot { state: 'running' | 'exited'; exitCode?: number; snapshot: string; shell: string }
  export interface TerminalSession { open(): TerminalSnapshot; write(data: string): void; resize(cols: number, rows: number): void }
  export function createTerminalSession(options: { spawn: SpawnPty; shell: string; cwd: string; env: Record<string, string>;
    onData: (chunk: string) => void; onExit: (exitCode: number) => void; logger: Logger; flushMs?: number; scrollbackBytes?: number }): TerminalSession
  ```

  Defaults: `flushMs = 8`, `scrollbackBytes = 262_144`.
